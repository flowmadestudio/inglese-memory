# Inglese Memory

Web app personale per imparare l'inglese partendo dall'ascolto, con scene, personaggi e ripasso distanziato.

- `index.html`: il percorso completo della parola *gate* (ascolto, domanda, aiuto, spiegazione, voci, pronuncia, scenetta di Alex, situazioni, ripasso).
- Audio: ElevenLabs. Teatrino e personaggio Alex: Higgsfield. Animazioni: codice.
- I progressi restano nel browser di chi la usa: nessun database.
